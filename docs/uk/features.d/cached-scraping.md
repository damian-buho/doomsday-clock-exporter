# Кешований збір із плавною деградацією

- Фоновий збирач отримує значення Годинника Судного дня від Bulletin of Atomic Scientists через налаштовувані інтервали.
- Зібрані значення кешуються з налаштовуваним TTL; збори Prometheus завжди повертають кешоване значення без блокування.
- Обслуговує застарілі значення з gauge деградації (`doomsdayclock_cache_stale=1`), коли джерело upstream недоступне.
- Збої збору вмикають повторні спроби з експоненційним backoff, максимум до 60 секунд.
